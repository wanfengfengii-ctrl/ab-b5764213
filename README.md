# 深空尾咬合卷积码 · 本地译码复核台

纯前端（TypeScript + React + Vite）的尾咬合卷积码（tail-biting convolutional code）
精确译码与逐时刻复核工具。**全部译码在浏览器本地完成，无任何后端计算。**

## 编码与译码约定

- 记忆阶数 `m ∈ [1,6]`，寄存器保存 m 个历史位，状态为 m 位整数。
- 状态转移：`next = ((state << 1) | bit) & ((1<<m)-1)`。
- 输出符号宽度为 `m+1` 位的**未截断寄存器字** `word = (state<<1)|bit`：
  对 2–3 个生成多项式分别取奇偶校验位 `parity(word & g)`，
  第一个多项式对应符号二进制最高位，因此 2/3 个多项式 → 4/8 个输出符号。
- 每个时间步对**全部输出符号**给出 `0..1,000,000` 的整数代价；步数 `8..512`。
- **初态必须等于末态**（尾咬合闭合，不发送清零尾比特）。
- 精确最小化整条闭合路径的总代价；总代价相同时，以**输入位串字典序最小**者为主结果，
  并报告最优是否唯一；存在并列时，展示异于主结果、字典序最小的另一条完整闭合见证。

> 注意：逐时刻贪心选择最低代价符号无法保证首尾状态闭合，也无法保证全局最优。
> 本工具采用**枚举全部初态（≤64）的 Viterbi**，在篱笆图上只保留真正闭合
> `s0 → … → s0` 的路径。

### 字典序 tie-break 的实现

给每条边权附加输入位串的字典序扰动：把位串按 `b0` 为最高位解释成整数 `lex`，
定义扰动权 `w = 真实代价 × 2^L + lex`（BigInt，避免任何溢出）。
比较 `w` 严格等价于“先比真实总代价，再比位串字典序”，因此 DP 直接取最小 `w`
即可稳定得到字典序最小的最优解。每个节点保留最优/次优两条不同路径（list-Viterbi），
用于在同一闭合端点上发现并列见证。

## 复核台功能

- 在线编辑或 JSON 导入/导出：记忆阶数、生成多项式（默认八进制，如 `133 171`，
  也支持 `0o/0x/0b` 前缀）、逐步符号代价表。
- 校验：阶数范围、多项式个数与寄存器宽度及非零、每步列数与符号数一致、
  代价为 `[0, 1_000_000]` 内整数、步数 8–512；**一次性定位全部错误**
  （字段 / 多项式序号 / 代价表行、列）。
- 输入一旦修改或校验失败，旧结果立即撤下并提示。
- 结果面板：初态(=末态)、总代价、唯一性、完整输入位串；时间轴表格逐时刻给出
  输入位、初态、未截断寄存器字、各多项式校验位、编码符号（二进制与十进制）、
  单步代价与累计代价，末步标注“回到初态”。另有时间游标可单步检查。
- 并列最优时提供“主结果 / 并列见证”两个页签。

## 本地开发

```bash
npm install
npm run dev       # 开发服务器
npm test          # vitest 单元测试（含小规模暴力枚举对照）
npm run build      # tsc 类型检查 + 生产构建到 dist/
npm run preview    # 本地预览静态产物
node scripts/smoke.mjs   # 静态 HTTP 冒烟（首页/健康检查/资源），退出码即结论
```

## Docker / Docker Compose

构建并启动静态站点（nginx 提供 `dist/`）：

```bash
docker compose up -d --build
# 宿主机端口可配置：
HOST_PORT=9090 docker compose up -d --build
```

- 默认访问 http://localhost:8080 ，容器内通过 `/healthz` 做健康检查
  （Compose 已配置 `healthcheck`）。

一次性复核服务 `verify`：依次运行**单元测试 → 构建检查 → 静态 HTTP 冒烟**，
完成后自行退出，并以退出码报告结果：

```bash
docker compose --profile verify run --build --rm verify
# 查看结论退出码（0 成功，非 0 失败）
echo $?
```

## 导入文件格式

```json
{
  "memory": 6,
  "polynomials": [91, 117],
  "costs": [[0, 120, 33, 201], "... 每步一行，4 或 8 列"]
}
```

`polynomials` 元素可为十进制数字，或 `0o133` / `0x5b` / `0b1011011` 形式的字符串。
